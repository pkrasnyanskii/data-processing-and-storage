# C1 — строки без повторяющихся подряд символов

По алфавиту (список односимвольных строк) и числу `N` строятся все строки длины `N`, в которых
нет двух одинаковых соседних символов. Без рекурсии и генераторов: только `reduce`, `map`,
`remove`, `apply concat` и `str`.

Идея: начинаем с одной пустой строки и `N` раз за `reduce` дописываем к каждому слову все буквы,
кроме той, которой слово заканчивается.

## Команды

Пример из условия (алфавит a, b, c, N = 2):

```bash
lein run
```

Тесты:

```bash
lein test
```

## Формула

Для алфавита из `k` букв получается `k · (k − 1)^(N − 1)` строк. Тест проверяет её на `k = 4, N = 4`
(108 строк), а `lein run` печатает 1536 = 3 · 2⁹ для `k = 3, N = 10`.
