# C4 — производственная линия

Линия делает часы с кукушкой (5 досок + 10 шестерёнок) и сейфы (3 металла). Шестерёнки и металл
делаются из руды, руду и доски добывают источники. Фабрики — агенты, склады — атомы вместе с
агентами. Дописана только функция `notify-msg` (и вспомогательные `take-from-storage!`,
`empty-buffer`), всё остальное из заготовки.

## Как работает notify-msg

1. Считаем, чего фабрике не хватает для цикла: `bill − buffer`.
2. Забираем со склада не больше этого количества (`swap-vals!`, вычитаем `min(остаток, нужно)`).
   Валидатор атома (`>= 0`) тут не срабатывает, исключение ловить не нужно.
3. Если буфер совпал с `bill` — ждём `duration`, шлём `supply-msg` на целевой склад и обнуляем
   буфер. Иначе просто возвращаем новый буфер.

## Нехватка металла

Руда уходит двум фабрикам: шестерёнкам (4 руды за цикл) и металлу (10 руды за цикл), а добывается
всего 2 в секунду. Если брать «всё или ничего», шестерёнки будут забирать руду каждые 4 штуки, а
металл не наберёт и 10. Поэтому фабрика забирает столько, сколько есть, и руда делится между двумя
потребителями. Сейфы выходят заметно реже часов, но выходят.

Фрагмент вывода за 100 секунд (часы появляются раз в 6–14 с, сейфы раз в 30–40 с):

```
12.46.49.270 | Cuckoo-clock amount:  1
12.47.03.264 | Safe amount:  1
12.47.32.281 | Safe amount:  2
12.48.09.310 | Safe amount:  3
12.48.13.314 | Cuckoo-clock amount:  10
```

## Команды

Запустить линию на 90 секунд (или на сколько секунд укажете) и завершить процесс:

```bash
lein run
lein run 120
```

Тесты:

```bash
lein test
```

## Заметка про `stop`

В заготовке `stop` вызывает `Thread.stop`, а в JDK 20 и новее он бросает
`UnsupportedOperationException`. Для запуска через `lein run` это не важно (процесс завершается
сам), а в REPL линию проще перезапускать перекомпиляцией, как написано в заготовке.
