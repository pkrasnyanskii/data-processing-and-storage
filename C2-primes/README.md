# C2 — бесконечная последовательность простых чисел

`task-c2/primes` — ленивая бесконечная последовательность простых, построенная решетом
Эратосфена без верхней границы.

Вместо массива с вычёркиванием хранится таблица «ближайшее составное число → простые, которые
через него прыгают». Для очередного `n`:

- `n` есть в таблице — составное, каждый его простой делитель `p` переезжает на `n + p`;
- `n` нет в таблице — простое: выдаём его и записываем `n²` (меньшие кратные уже вычеркнуты
  меньшими простыми).

## Команды

Первые 20 простых (или любое другое число аргументом):

```bash
lein run
lein run 50
```

Тесты:

```bash
lein test
```

Тесты проверяют начало последовательности, известные значения (1000-е простое — 7919, 25 простых
меньше 100, 1229 меньше 10000), ленивость, и сверяют первые простые до 5000 с проверкой делением.
